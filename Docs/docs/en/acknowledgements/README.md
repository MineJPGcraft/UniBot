## How to Support Us

If you like this project, you can support us in the following ways:

- **Star** our [GitHub repository](https://github.com/MineJPGcraft/UniBot) so more people can discover it.
- **Submit Issues / PRs** to help us find and fix problems.
- **Sponsor** to provide support for the developers and the motivation to move forward.
- **Spread the word** and recommend UniBot to friends who need it.

> ::fluent-color:heart-24:: No matter what, thank you to every supporter — it is your help that makes this project go further!
