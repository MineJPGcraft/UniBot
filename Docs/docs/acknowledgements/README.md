## 如何支持我们

如果你喜欢这个项目，可以通过以下方式支持我们：

- **Star** 我们的 [GitHub 仓库](https://github.com/MineJPGcraft/UniBot)，让更多人看到它。
- **提交 Issue / PR**，帮助我们发现并修复问题。
- **赞助**，为开发者提供支持，以及前进的动力。
- **宣传**，把 UniBot 推荐给需要的朋友。

> ::fluent-color:heart-24:: 无论如何，感谢每一位支持者，正是你们的帮助让项目走得更远！
